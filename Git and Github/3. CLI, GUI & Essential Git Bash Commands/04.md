### Assignment 4: File & Folder Operations (Practical)

**Objective:** Practice creating, copying, moving, and deleting files/folders.

**Tasks:**
Perform the following in Git Bash and write the exact commands:

1. Create a folder `Project`
2. Inside `Project`, create a file `index.html`
3. Create another file `about.txt` using `echo` with any text
4. Copy `index.html` and name the copy as `home.html`
5. Rename `about.txt` to `about-me.txt`
6. Create a folder `Backup` and copy the entire `Project` folder into it
7. Delete `home.html`
8. Show the content of `about-me.txt`
9. Delete the `Backup` folder

**Also answer:**
- What is the difference between `rm` and `rm -r`?
- Why should we be careful while using `rm -rf`?
